# Tshaku Nuxt

This repository is a Nuxt 3 migration/starter for the original PROGRAMAGE/tshaku project.

Quick start

1. Install dependencies

   npm install

2. Run in development

   npm run dev

3. Build

   npm run build

4. Preview production build

   npm run preview

What this contains

- Nuxt 3 app scaffolded for SSR
- Pinia store example
- Axios plugin (injected as $axios)
- Example server API (server/api/hello.get.ts)

Notes

- This is a starting point. You will need to migrate your components, pages, and assets from the original repository into this project. Use the pages/ directory for file-based routing and stores/ for Pinia stores.
